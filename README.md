# 競艇AI予想 v3.3

v3.2を基に、過去90日間・全24場の一括参考シミュレーションと競艇場別の回収率ランキングを追加しました。

- 最大90日間、日別CSVを最大3日並列で取得
- 検証進捗と中止ボタン
- 競艇場別：検証レース数、的中数、的中率、投資、払戻、回収率
- レース詳細は先頭300件のみ表示（ブラウザ負荷軽減）
- 既存の出走表取得と予測機能は維持

**注意**: 過去の出走表から現在のルールベースモデルを再計算した参考シミュレーションです。学習済みモデルの厳密な事前予測検証ではありません。公開CSVの欠損・仕様変更・CORSやアクセス制限により一部の日付は取得できない可能性があります。回収率ランキングは将来の利益を保証しません。

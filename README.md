# 競艇AI予想 v3.2

既存のv3.1に「公開CSVから過去レースを自動検証」を追加。

## データ
- 出走表: `data/programs/race_cards/YYYY/MM/DD.csv`
- 確定三連単・払戻: `data/results/payouts/YYYY/MM/DD.csv`
- 着順との照合（取得できる場合）: `data/results/realtime/YYYY/MM/DD.csv`

取得元: https://boatracecsv.github.io/

## 手順
開始日・終了日（最大14日間）、場、買い目数、1点の購入額を指定して「公開CSVから自動検証」。日付ごとに公開CSVを読み、6艇の出走表があるレースについて現行のルールベースモデルを再計算し、確定払戻を用いて的中率と回収率を集計します。欠損や不一致は除外し、未取得日数を表示します。

## 重要な制約
これは「当時の出走表から現行モデルを再計算した参考シミュレーション」です。レース前に保存した予測CSVを評価する既存の機能とは別です。展示タイムは使いません。出走表がレース後に修正されていないことや当時の公開時刻は検証できません。結果を見て調整したモデルで同じ期間を検証すると過大評価になります。利益や的中は保証されません。

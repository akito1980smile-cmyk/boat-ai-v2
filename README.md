# 競艇AI予想 v3.5

v3.4の公開CSV出走表取得、90日間検証、場別ランキングを維持。

## 新概念データ試験機能
- BOATBoy公式サイトからの自動取得・スクレイピングは実装していません。
- 利用者が適法に利用できるCSVをブラウザ内で読み込み、現在のレースに一致した行だけ実験的な係数補正に使用します。
- CSV列は `date,venue,race,lane,win1,escape2,makuri,sashi`。日付はYYYY-MM-DD、venueは01〜24、率は0〜100。
- 読み込んだCSVは外部送信しません。ページ更新で消えます。
- 過去検証は従来モデルのままで、新概念データ反映モデルの回収率検証ではありません。
- 補正は未検証の仮説です。BOATBoyによる推奨や承認を意味しません。

BOATBoy利用規約: https://www.boatboy.jp/rule/


## v3.7 新概念データの複数CSV統合

- 「新概念データ」欄でCSVを複数選択できます。追加選択したCSVは既存データに統合されます。
- キーは `date,venue,race,lane` です。同一キーは後から読み込んだ行が優先され、重複件数を表示します。
- 登録行数、レース数、6艇揃ったレース数、未完成レース数を表示します。
- 「統合CSVを保存」で登録データを保存できます。「登録データをクリア」で全件消去します。
- 取り込みエラー時は既存データを維持します。ブラウザ再読込で登録データは消えます。
- BOATBoyサイトからの自動収集は行いません。使用権限があるCSVのみ登録してください。
- 過去のON/OFF比較は、6艇分揃ったレースのみを対象とし、データの事前入手時点は自動検証できません。


## v3.8 新概念データ入力の改善
- 複数CSVのファイル選択に加え、ドラッグ＆ドロップ、CSVテキスト貼り付けを追加。
- 上部の日付・競艇場と開始R～終了Rから、6艇×指定レースの空欄CSVテンプレートを作成できます。
- 読み込みは全行を検証後に統合するため、エラー時は登録済みデータを変更しません。
- ブラウザのlocalStorageへ自動保存・再読込時復元。端末・ブラウザ間では共有されず、削除される場合があります。統合CSVでバックアップしてください。
- 既存の予測・過去検証・ON/OFF比較の計算方式は変更していません。
- 公式サイトの自動取得機能はありません。データの利用権限と取得時点を確認してください。


## v3.9 競艇場別統計CSV読み込み
- 画面の「競艇場別統計CSV」から venue_recent_course_rates.csv を選択。複数ファイル選択可能。
- 補正を有効化すると現在のレースの6艇の強度に小幅な倍率（0.85～1.15）を適用。
- 過去検証は従来ロジックのまま。データはブラウザを再読み込みすると消えるので再度読み込んでください。
- venue_2026_first_course.csv は1コースの参考表示のみ。複数CSVで同一場が重なる場合、後から読み込んだ行を優先。
- これは統計的に校正されたモデルではなく、補正による精度向上は未検証です。

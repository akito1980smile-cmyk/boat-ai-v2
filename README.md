# 競艇AI予想 v3.1

公開CSVからの出走表取得・三連単120通りのルールベース推定・予算配分・予測CSV保存を維持し、過去レースの検証機能を追加しました。

## GitHub Pages更新
ZIPを展開し、中の `index.html`、`app.js`、`data/`、`scripts/`、`.github/` を既存リポジトリのルートへ配置します。フォルダ `boat-ai-v3.1` 自体を入れ子でアップロードしないでください。

## 検証手順
1. 各レースの開始前に「予測CSVを保存」で予測120通りを保存します。
2. 結果が確定したら `data/results_example.csv` を参考に `race_id,actual,payout` のCSVを作ります。`payout` は100円あたりの確定払戻円。未確認なら空欄。
3. 過去の予測CSVを複数選択し、確定結果CSVを選んで「検証を実行」。
4. 上位N点を1点100円以上の均等額で仮想購入した場合の的中率と回収率、正解買い目の対数損失・Brierスコアを表示します。

同一レースの予測CSVを重複投入するとエラーになります。120通り欠損・確率合計異常・結果不明のレースは検証対象外です。回収率は払戻情報のあるレースのみ集計します。CSVの作成時刻は検証できないため、予測がレース前に保存されたことは利用者が管理してください。過去レースの結果自動取得・学習・校正は未実装です。

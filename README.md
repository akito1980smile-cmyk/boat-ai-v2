# 競艇AI予想 v3

GitHub Pages対応の静的アプリです。v2.1の公開CSV取得を維持し、三連単120通りの逐次選択型確率計算、買い目選択、100円単位予算配分、予測CSVエクスポートを追加しました。

## 公開方法
ZIPを展開し、`index.html` と `app.js`、`data/`、`.github/`、`scripts/` をリポジトリのルートにアップロードします。GitHub Settings → Pages → Deploy from a branch → main / (root)。

## 注意
確率は手動設定した強度によるルールベース推定で、学習済みAIや校正済み確率ではありません。期待値はオッズ手動入力が必要です。B80直接収集・オッズ自動取得・自動バックテストは未実装です。実績検証は過去の予測・結果・払戻CSVを読み込んで行います。データの更新や配信は外部公開元に依存します。

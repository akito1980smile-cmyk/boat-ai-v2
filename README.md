# 競艇AI予想 v2

スマートフォン対応の静的Webアプリ。B80の画面を参考にしていますが、B80アプリには接続しません。

## GitHub Pages 公開
1. ZIPを展開し、**中身**をGitHubリポジトリのルートへアップロード。
2. Settings → Pages → Deploy from a branch → main / (root) → Save。
3. 数分後に公開URLを開き、日付・場・レースを選んで「データ取得」。
4. GitHub Actionsの `Update public boat race cache` は毎日22:15 JSTにCSVを取得してコミットします。Actionsの書き込み権限が必要な場合は Settings → Actions → General → Workflow permissions を確認。

## v2の機能と制限
- 全国24場・12Rの選択UI。
- BoatraceCSVの公開出走表CSVをブラウザで直接取得（CORS、提供元の列名・更新状況に依存）。現環境では外部HTTP接続ができず、実CSVのパース動作は未検証です。列名が一致しない場合は app.js の normalize() を調整してください。
- 出走表・全国/当地勝率・モーター2連率・展示タイムの表示（CSVに存在しない項目は空欄）。
- 6艇の強さスコアを使う**暫定ヒューリスティック**で三連単120通りを計算。**学習済みAIではなく、確率の校正も未実施**。精度や収益性は保証しません。
- オッズは手動CSV風テキスト入力。公開出走表にオッズが含まれないため、オッズの自動取得は未実装。
- 買い目候補と予算均等配分（100円単位）。
- 過去予測CSVを読み込み的中率・回収率を集計。過去レースの予測履歴を自動生成する機能は未実装。サンプルCSVはテスト用架空の結果です。
- `scripts/fetch.py` は公開CSVを保存するだけで、ブラウザ表示のデータ取得先は公開元です。キャッシュをUIに優先利用する連携は未実装。
- B80の内部APIへの接続や自動抽出は未実装。規約と利用権限の確認が必要です。

## データ提供・注意
- https://boatracecsv.github.io/ （非公式、MIT License、データ提供元の条件を確認）
- https://boatrace.jp/owpc/pc/extra/data/download.html
- 日付は日本時間。公開データの遅延・欠損あり。賭け金の支出は自己責任で。

## ローカル確認
`python -m http.server 8000` をリポジトリルートで実行し、http://localhost:8000 を開く。
